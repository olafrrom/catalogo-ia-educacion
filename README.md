# Catálogo de herramientas de IA para educación

Repositorio editorial curado para identificar herramientas de inteligencia artificial por uso pedagógico, no por tendencia tecnológica.

**Curación y diseño editorial:** Olaf Román  
**Versión:** 1.0  
**Formato:** sitio estático para GitHub Pages  

---

## Descripción

Este catálogo reúne herramientas de inteligencia artificial organizadas por función educativa. Cada ficha está diseñada para ayudar a docentes, diseñadores instruccionales, formadores y equipos académicos a decidir qué herramienta usar, cuándo usarla y con qué propósito pedagógico.

El catálogo prioriza herramientas que aportan un flujo pedagógico diferenciado. Su criterio principal es el valor educativo, la claridad de uso y la pertinencia para procesos de enseñanza, aprendizaje, evaluación, investigación, accesibilidad y producción didáctica.

---

## Criterio editorial

Una herramienta entra al catálogo si cumple al menos una de estas condiciones:

- Aporta un flujo pedagógico diferenciado.
- Resuelve una necesidad educativa concreta.
- Facilita diseño, evaluación, accesibilidad, investigación o producción didáctica.
- Apoya procesos de construcción de conocimiento, metacognición o aprendizaje activo.

---

## Estructura de cada ficha

Cada herramienta incluye:

- Nombre
- Categoría
- Descripción corta
- Botón de acceso
- Ficha pedagógica desplegable
- Descripción extendida
- Tres casos de uso con prompt
- Tres ventajas
- Tres limitaciones

---

## Categorías principales

- Accesibilidad
- Construcción de conocimiento
- Diseño instruccional y planeación
- Evaluación y retroalimentación
- Investigación
- Metacognición y autorregulación
- Producción audiovisual
- Productividad y gestión
- Recursos sonoros
- STEM y low-code

---

## Uso del catálogo

Este recurso puede utilizarse para:

- Explorar herramientas de IA según una necesidad educativa concreta.
- Comparar posibilidades pedagógicas entre herramientas.
- Diseñar actividades, recursos, evaluaciones o procesos de apoyo académico.
- Orientar decisiones docentes sobre el uso pertinente de IA en educación.

## Publicación en GitHub Pages

1. Entrar a la configuración del repositorio:

```txt
Settings → Pages
```

2. En **Build and deployment**, seleccionar:

```txt
Deploy from a branch
```

3. Elegir:

```txt
Branch: main
Folder: /root
```

4. Guardar los cambios.

La URL tendrá esta estructura:

```txt
https://olafrrom.github.io/catalogo-ia-educacion/
```
